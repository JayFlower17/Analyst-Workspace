# 模块说明：dataset

## 1. 模块定位

`dataset` 模块负责把外部文件转成平台内部可分析的数据表对象。

它是整个平台的数据入口。

---

## 2. 负责什么

- CSV / Excel 上传
- 导入 DuckDB
- 数据集元信息保存
- 列元数据提取
- 数据预览
- 数据表描述维护
- 与 workspace 的挂接

---

## 3. 不负责什么

- 不负责生成分析结论
- 不负责聊天会话管理
- 不负责 SQL / Python 生成

---

## 4. 当前状态

当前已基本成型：

- 支持 CSV / Excel 上传
- 自动导入 DuckDB
- 保存数据集信息
- 保存列元数据
- 支持数据预览
- 支持数据表描述更新

此外还预留了元数据向量化的 Hook，用于后续 RAG 能力。

---

## 5. 当前问题

1. 数据集描述虽然有接口，但前端新主线还没完全接上
2. 数据预览能力在 Next 前端还未补齐
3. 数据集和 workspace 的业务语义还可以更清晰

---

## 6. 后续演进方向

`dataset` 模块后续要继续强化“可理解性”，不仅是“能导入”：

- 表描述更容易维护
- 字段含义更容易阅读
- 预览更稳定
- 更好地服务 workspace 分析上下文
