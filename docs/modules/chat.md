# 模块说明：chat

## 1. 模块定位

`chat` 模块是平台的探索式分析入口。

它让用户不需要先进入正式 workspace，就可以先上传数据、发起提问、快速获得结果。

---

## 2. 负责什么

- 聊天会话创建与切换
- 会话消息记录
- 会话内数据集上传
- 会话内数据集绑定
- 会话中的分析请求
- 从 chat 升级为 workspace

---

## 3. 不负责什么

- 不负责底层 SQL / Python 执行
- 不负责长期正式的数据组织结构
- 不负责复杂报表管理

`chat` 是探索入口，不是最终治理中心。

---

## 4. 当前状态

当前 `chat` 已经具备完整雏形：

- 会话列表
- 消息列表
- 上传数据到会话
- 指定数据集分析
- 无数据集时退化为普通 AI 助手回复
- 升级为 workspace

这说明 chat 已经不是简单对话框，而是一个轻量分析工作入口。

---

## 5. 当前问题

1. 前端两套实现并存
2. 会话结果沉淀还偏“最近一次结果”
3. artifact 与历史回看能力还没真正形成产品体验

---

## 6. 后续演进方向

`chat` 后续定位应稳定为：

- 用户进入平台后的第一站
- 用于快速试数据、快速提问、快速看到结果
- 当分析变复杂时，引导进入 workspace

换句话说：

**chat 负责探索，workspace 负责沉淀。**
