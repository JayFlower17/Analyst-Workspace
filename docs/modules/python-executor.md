# 模块说明：python-executor

## 1. 模块定位

`python-executor` 是一个受限执行模块。

它的职责不是理解业务，而是在后端分析流程需要时，安全地执行 AI 生成的 Python 代码，并返回结果。

---

## 2. 负责什么

- 提供独立执行服务
- 校验 Python 代码安全性
- 在受限环境中执行代码
- 将 DuckDB 表数据加载为 DataFrame
- 返回结构化结果和摘要
- 控制超时和结果规模

---

## 3. 不负责什么

- 不负责决定什么时候执行 Python
- 不负责生成 Python 代码
- 不负责工作区上下文拼装
- 不负责用户交互

这些职责属于后端 analysis 编排层。

---

## 4. 当前状态

当前执行器已经有：

- FastAPI 服务入口
- Python 代码白名单校验
- 子进程执行隔离
- 超时控制
- DataFrame 结果回传

它已经是一个“可用的受限执行器”，但仍然是平台的底座能力，不应该直接承担业务逻辑。

---

## 5. 当前问题

1. 本质上仍依赖 `exec`，安全边界需要持续审查
2. 当前执行方式以单表 DataFrame 为主
3. 多表 workspace 下的 Python 联合分析尚未真正补齐

---

## 6. 后续演进方向

短期：

- 继续保持“受限执行器”定位
- 不把业务编排下沉到这里

中期：

- 视需要支持更明确的多表数据装载方式
- 提升安全校验和可观测性
