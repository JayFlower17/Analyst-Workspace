# 模块说明：frontend

## 1. 模块定位

前端模块负责把平台能力组织成用户可操作的产品界面。

当前仓库中存在两套前端：

- `frontend/`：Vue 3 版本
- `frontend-next/`：Next.js 版本

项目当前决策是：

**`frontend-next/` 为未来主线，`frontend/` 作为迁移期保留版本。**

---

## 2. 负责什么

前端负责：

- 登录注册交互
- 数据集上传与浏览
- 聊天分析体验
- workspace 管理与分析
- 分析结果展示
- 用户状态和导航组织

---

## 3. 不负责什么

前端不负责：

- 用户认证的真实校验
- SQL / Python 生成
- 数据导入解析
- 数据库存储
- 执行安全

前端只负责调用后端 API，并把能力组织成稳定的用户流程。

---

## 4. 当前状态

### `frontend/`（Vue）

优点：

- 功能覆盖更完整
- 已接入较多后端接口
- 当前可以承担可用版本

缺点：

- 页面和产品结构偏旧
- 长期演进成本更高
- 不适合作为最终主前端

### `frontend-next/`（Next）

优点：

- 更接近未来产品形态
- 页面结构更清晰
- 更适合作为长期主线

缺点：

- 仍缺少部分管理能力
- 鉴权闭环和部分页面能力还未补齐

---

## 5. 当前职责分配

### Vue 版

只承担：

- 维持当前可用
- 必要的小修

不再承担：

- 新的大功能开发
- 长期产品形态探索

### Next 版

承担：

- 后续所有新增能力
- 新交互和新信息架构
- 最终替代 Vue

---

## 6. 后续演进方向

前端后续需要围绕以下页面结构收敛：

1. `login / register`
2. `chat`
3. `datasets`
4. `workspace`
5. `artifacts`（后续新增）

同时统一术语：

- 优先使用 `workspace`
- 避免 `workspace / workplace` 混用
