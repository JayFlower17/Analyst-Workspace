# 当前写作提示

这份论文最适合强调的三条主线：

1. **交互式分析**
   用户通过问答与工作区方式发起分析，而不是直接编写 SQL。

2. **AI 智能体辅助分析**
   系统通过大模型理解用户问题，生成 SQL 或 Python 执行逻辑，并结合文档上下文提升分析能力。

3. **结构化与非结构化联合分析**
   系统同时支持表格数据与文档知识，能够在工作区中形成统一分析上下文。
